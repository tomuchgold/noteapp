# NotePP v0.9.0 发布说明

发布日期：2026-11-18

## 新功能

### 缩放（打印大字）
- Ctrl/⌘ + 滚轮缩放编辑区字号，**放大上限 900px**（可导出 HTML / 直接打印大字）
- **Ctrl+0** 一键复位 100%，状态栏显示当前缩放百分比、点击复位
- 缩放随基准字号叠加（设置里基准字号 11–24px，缩放 25%–6500%）

### 段落高亮 + 反色选区
- 光标所在整段（空行分隔的连续行块）亮色背景高亮，比单行高亮更醒目，可开关
- 段内鼠标选取的文字**反色显示**（背景/文字互换），高亮段落上也清晰可辨

### 多主题系统
- 内置 8 套主题：暗色 / 亮色 / 羊皮纸 / 日光（Solarized）/ 护眼绿 / Nord / Dracula / 赛博
- 设置面板色卡选择，所见即所得
- 自定义主题 JSON **导入 / 导出 / 模板**，主题可增量扩充（localStorage 持久化）

### 划线 / 标注 / 标注信息
- 选中文本右键：**高亮标注**（黄/绿/蓝/粉/橙 5 色）、**划线**、**标注信息（备注）**
- 备注悬停显示；右键命中标注可直接删除
- 标注随编辑自动位移，按文件路径持久化；重载时按原文快照校准定位

### Markdown 增强
- GFM 表格语法高亮样式
- 菜单「表格」按行/列插入 Markdown 表格模板
- 「预览」实时渲染（GFM），支持**导出带样式 HTML**（沿用当前缩放字号，可直接浏览器打印为 PDF）

### 拖拽多媒体与附件
- 拖入图片/音频/视频/任意附件：文件自动复制到**文档同目录 media/**（同名加序号），光标处插入引用
  - 图片 `![名](media/x.png)`，音频 `<audio controls>`，视频 `<video controls>`，其他附件链接
- 文本文件拖入仍按原文档打开；未保存文档会先提示保存
- 混合内容直接保存，md/html 中均可渲染引用

## 安装 / 升级

见 [INSTALL.md](./INSTALL.md)。macOS 首次打开如提示「已损坏」，执行：
`xattr -cr /Applications/NotePP.app`

## 已知限制
- 自动更新仍为「检查 + 提示」；真正静默安装需代码签名证书
- 标注持久化基于位置+原文快照，大幅删改后个别标注可能自动丢弃

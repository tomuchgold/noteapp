NotePP 功能手册

从文件管理到 AI 写作，一份覆盖全部功能的完整使用指南。对应版本 v0.23.0，适用于 macOS / Windows / Linux / Android。

当前版本 v0.23.0 12 大功能类别 技术栈 Tauri 2 + React 19 + CodeMirror 6 数据 全部本地存储

01 📁 文件与标签

多文件工作流、本地文件库与文件夹浏览，大文件也有对应的轻量方案。

🗂️多标签编辑

是什么多个文件同时打开在顶部标签栏，未保存的标签以 ● 标记。
怎么用Ctrl+Tab 依次切换标签；中键点击标签直接关闭；也能用菜单「关闭」。
路径顶部标签栏 / 菜单栏「关闭」　快捷键Ctrl+TabCtrl+W

🆕新建 / 打开 / 保存 / 另存为

是什么使用系统原生文件对话框，支持把文件直接拖进窗口打开。
怎么用保存覆盖当前文件；另存为可导出到其他路径或编码；大文件只读模式下请用「另存为」导出已加载部分。
路径菜单栏「新建 / 打开 / 保存 / 另存为」　快捷键Ctrl+NCtrl+OCtrl+SCtrl+Shift+S

🕘最近文件

是什么自动记录最近打开的 10 条文件路径。
怎么用点击菜单栏右侧「最近文件」下拉框，按文件名或完整路径选择即可再次打开。
路径菜单栏右侧「最近文件」下拉列表

🗃️文件库与分类管理

是什么打开过的文件自动进入文件库，可用带颜色的分类归档。
怎么用在左侧分类侧栏新建分类并指定颜色，右键文件归类，可收藏置顶与搜索过滤；所有数据本地持久化。
路径左侧分类侧栏　显隐Ctrl+B

🌳文件夹树

是什么侧栏内置目录树，方便在项目里逐层浏览，右键即可完成常用的本地文件操作。
怎么用点击侧栏「打开」按钮选择文件夹，逐层展开后直接点击文件打开；隐藏文件自动过滤。
路径侧栏「打开」按钮 → 选择文件夹

🖱️文件夹树右键菜单

是什么在目录树或空白处点击右键，可新建文件 / 新建文件夹 / 重命名 / 删除 / 在系统中显示 / 全部打开 / 切换文件夹。
怎么用右键空白处作用于根目录；右键文件夹可新建或一键打开其中所有文本；双击空白处直接新建文件；Esc 关闭菜单。新建 .md 自动带标题模板，.json 自动带花括号骨架；删除会同步关闭已打开的对应标签。
路径侧栏文件夹树 → 右键

📎系统文件关联与单实例

是什么安装后，txt / md / log / json / yaml / toml / csv / html / css / js / ts / py / rs / go / java / c / cpp / sh / sql 等常见文本格式可在系统里「打开方式」中选择 NotePP；双击文件即可打开。同时应用为单实例：重复打开文件不会另起新窗口，而是在已开窗口里新增标签。
怎么用双击文件或在「打开方式」里选 NotePP；传入的是文件夹时自动打开侧栏目录树；macOS 上 Finder 双击同样生效。
路径系统文件管理器 → 打开方式 → NotePP

🫳拖拽打开文件与文件夹

是什么把文件或整个文件夹拖进窗口：文本文件开成标签，图片/音频/视频插入当前文档作为附件，文件夹直接成为侧栏目录树根目录。
怎么用从资源管理器把任意路径拖到 NotePP 窗口内松手即可。
路径拖入窗口 → 自动识别文件 / 文件夹 / 媒体

📚大文件只读模式

是什么超过 8MB 的文件自动以只读分块方式打开，每块 1MB，按需「再加载」，不会一次占满内存。
怎么用状态栏显示「已加载 / 共」大小与继续加载入口。该模式不支持直接保存与插入媒体，可「另存为」导出已加载部分。
路径打开大文件后自动进入 · 状态栏显示模式

🔔外部文件变更监听

是什么应用会轮询磁盘文件的修改时间（mtime）与大小。
怎么用当文件在外部被其它程序修改时，会给出提示并支持自动重载，避免基于旧内容编辑造成覆盖。
路径自动监听，无需手动开启

02 ✏️ 编辑体验

编辑器本色：缩放、高亮、换行与矩形选区，都能按习惯调。

🔠文字变换

是什么一键完成常见文本整理：转为大写 / 转为小写 / 首字母大写 / 行排序 A→Z / 行排序 Z→A / 去除重复行 / 去除行首尾空格。
怎么用选中文字后点菜单栏「🔠 变换」选择即可；大小写类无选中时作用于当前行，排序/去重/去空格无选中时作用于全文。转大写默认 Ctrl+Alt+U，转小写 Ctrl+Alt+I，均可在「快捷键设置」里改键。
路径菜单栏「🔠 变换 ▾」

📂右键打开所在文件夹

是什么在标签页、文件列表、文件夹树的任意文件上点右键，可直接把该文件所在的文件夹打开为侧栏目录树；也可选「在系统中显示」由系统文件管理器定位。
怎么用右键标签 / 文件列表条目 / 目录树文件 → 「📂 打开所在文件夹」或「🖥️ 在系统中显示」。
路径标签页 / 文件列表 / 文件夹树 → 右键

🔠正文缩放（最大 900px）

是什么正文字号可实时放大到上限 900px，做标题、贴海报、直接打印大字都方便。
怎么用Ctrl/⌘ + 滚轮 缩放，Ctrl+0 复位 100%。设置里也有基准字号（11–24px）与缩放比例滑块。
路径菜单栏「设置」→ 正文字号缩放　快捷键Ctrl+滚轮Ctrl+0

🖊️当前行与当前段落高亮

是什么光标所在行 / 整段以醒目底色标出；默认用主题强调色淡染并带左竖条，与标注色系明显区分。
怎么用在「设置」中勾选当前行高亮与当前段落高亮，可用取色器自定义高亮颜色，也可一键「跟随主题」。
路径菜单栏「设置」→ 当前行高亮 / 当前段落高亮 / 高亮颜色

↩️自动换行、空白符与 Tab 宽度

是什么长行自动换行、空格与 Tab 可视化、缩进宽度可调，帮助看清排版结构。
怎么用「设置」中勾选自动换行、显示空白符；Tab 宽度可选 2 / 4 / 8 空格；行高也可在 1.2–2.4 之间调节，实时生效并持久化。
路径菜单栏「设置」→ 自动换行 / 显示空白符 / Tab 宽度 / 行高

▦列编辑（矩形选区）

是什么开启后拖拽形成矩形选区，多行同时输入同一段文字；遇到短行或空行会自动补空格，保持选区成一条直线。
怎么用点击菜单「列选」开启（按钮高亮），然后按住拖拽；也可直接 Alt + 拖拽 临时进入列编辑。
路径菜单栏「列选」或 Alt+拖拽

📊插入 Markdown 表格

是什么一键在光标处插入 GFM 表格模板，免去手写表头分隔行。
怎么用把光标放到目标位置，点击菜单「表格」，随后直接编辑单元格内容即可。
路径菜单栏「表格」（需先打开一个文件）

03 🎨 主题外观

8 套内置主题覆盖整个界面，自定义主题用 JSON 描述、导入导出。

🌈8 套内置主题

是什么暗色（默认）、亮色、羊皮纸、日光（Solarized）、护眼绿、Nord、Dracula、赛博，共 8 套。
怎么用打开「设置」→「编辑器主题」，点击色块即可切换，正文与配色实时生效。
路径菜单栏「设置」→ 编辑器主题

🧩自定义主题（JSON 导入 / 导出 / 模板）

是什么主题以 JSON 描述（背景、前景、强调色、段落色等），可增量扩充而不覆盖内置主题。
怎么用在主题区点击导出模板获取样例，改好颜色后用导入主题加载；导出我的主题可把自定义主题打包成 JSON 备份或分享。
路径菜单栏「设置」→ 编辑器主题 → 导入主题 / 导出我的主题 / 导出模板
{
  "id": "my-theme",
  "name": "我的主题",
  "colors": {
    "bg": "#1e1e2c", "fg": "#e6e6f0",
    "accent": "#61afef", "para": "#333846"
  }
}

🖥️主题覆盖整体界面

是什么主题配色与界面字号倍率会注入应用根元素，菜单、侧栏、状态栏、按钮等所有 UI 都随之变化，风格统一。
怎么用「设置」中调整界面字号倍率（70%–200%）影响全局 UI；改主题后无需重启。
路径菜单栏「设置」→ 界面字号

🔍查找框字号倍率

是什么查找 / 替换浮窗可单独设置字号倍率（70%–200%），在界面倍率基础上叠加，方便演示或大屏阅读。
怎么用「设置」→「查找框字号」拖动滑块；设置即时反映到浮窗。
路径菜单栏「设置」→ 查找框字号

04 🔎 查找替换

单文件、跨文件夹与所有标签页三种范围，Notepad++ 风格结果面板。

🔤当前文件查找

是什么实时高亮全部命中，当前命中单独标色，并显示 n/N 命中计数。
怎么用Ctrl+F 打开查找；Ctrl+H 打开并聚焦替换框；在查找框内 Enter / Shift+Enter 跳下一处 / 上一处；Esc 关闭。
路径菜单栏「查找」　快捷键Ctrl+FCtrl+HEsc

🗂️跨文件夹 / 所有打开标签查找

是什么查找范围可选：当前文件、整个文件夹、或所有已打开的标签页。
怎么用在查找面板选择范围并输入关键字，匹配结果汇总到窗口底部的结果面板。
路径查找面板 → 选择搜索范围

⚙️匹配选项与替换

是什么支持正则、区分大小写、全词匹配三种选项；替换可逐个进行或全部替换（可撤销）。
怎么用在查找 / 替换浮窗勾选所需选项，填入替换文本，点「替换」或「全部替换」。
路径查找浮窗 → 选项与替换按钮

PRE替换逐条预览

是什么点「全部替换」不再盲替换：先列出每一处命中的行号、替换前、替换后，可筛选并逐条勾选。
怎么用填好查找与替换文本 → 点「全部替换（预览）」→ 在弹窗里取消不需要的项 → 点「执行替换」。正则模式支持 $1～$9 捕获组。
路径查找浮窗 → 全部替换（预览）

🪟可拖动的查找浮窗

是什么查找浮窗可从主窗口拖出，放到副屏使用；字号可通过「查找框字号」倍率单独调整。
怎么用按住浮窗标题栏拖动即可脱离主窗口；拖回窗口区域可重新停靠。
路径查找浮窗标题栏（拖动）· 字号见「设置 → 查找框字号」

📋Notepad++ 风格结果面板

是什么底部结果面板按 行号 + 命中行内容 展示，命中词高亮，点击任意结果直接跳转到对应行。
怎么用执行跨文件夹 / 全部标签查找后自动出现；用 F3 / Shift+F3 在命中间循环。
路径查找后面板底部显示　快捷键F3Shift+F3

05 📝 Markdown

完整 GFM 加数学、图表与代码高亮，写完可直接预览、导出。

📄完整 GFM 支持

是什么标题、列表、任务列表、表格、引用、链接、围栏代码块等 GitHub Flavored Markdown 语法。
怎么用像普通文本一样编辑 .md 文件，点击「预览」即可看到渲染效果。
路径菜单栏「预览」

∑KaTeX 数学公式

是什么支持 LaTeX 语法的数学公式渲染，行内与块级均可。
怎么用行内公式用 $...$，独立公式用 $$...$$，在预览中查看排版结果。
路径Markdown 正文 → 预览
行内：$ E = mc^2 $
块级：
$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

📊Mermaid 图表

是什么在 Markdown 中用 Mermaid 代码块描述流程图、时序图等，预览时渲染成图。
怎么用使用 ```mermaid 围栏代码块写入图表定义。
路径Markdown 正文 → 预览
```mermaid
graph LR
  A[写笔记] --> B(预览)
  B --> C[导出 HTML]
```

🖍️highlight.js 代码高亮

是什么围栏代码块按语言着色，编辑器内还支持 25+ 语言（JS/TS/Python/Rust/Go/SQL 等）按扩展名识别。
怎么用在代码围栏后标注语言名，如 ```python，预览时自动高亮。
路径Markdown 正文 → 预览

👁️渲染预览与导出带样式 HTML

是什么所见即所得的渲染预览；非 Markdown 文件按纯文本预览；支持导出保留样式的 HTML。
怎么用点击菜单「预览」打开预览面板，从中导出 HTML，或直接打印成 PDF。
路径菜单栏「预览」→ 导出带样式 HTML

06 ⚖️ 对比与预览

分屏查看、双文件逐行 Diff，以及打印 / 导出 PDF。

🪟分屏对照

是什么左右两栏同时查看两个文件，适合并排核对。
怎么用点击菜单「分屏」（按钮高亮）开启，再次点击关闭。
路径菜单栏「分屏」

🔀双文件对比对话框

是什么从已打开标签或磁盘选择两个文件，进入左右分栏 Diff 视图：删除 / 新增高亮，未变化区域自动折叠。
怎么用点击菜单「对比」，在对话框中选择两个文件后确认。
路径菜单栏「对比」

🔬逐行对比与渲染预览双模式

是什么对比视图提供两种模式：逐行对比（带语法着色）看文本差异，渲染预览看最终呈现效果。
怎么用在对比 / 预览面板中切换模式，按需查看代码级差异或文档级效果。
路径对比视图 / 预览面板的模式切换

🖨️打印 / 导出 PDF

是什么按当前缩放字号打印文档，在系统打印对话框里选择「另存为 PDF」即可导出。
怎么用点击菜单「打印」或按 Ctrl+P，在打印目的地中选 PDF。
路径菜单栏「打印」　快捷键Ctrl+P

07 🖍️ 标注

划线、高亮、备注随文字自动位移，按文件持久化；面板里还能朗读、复制、粘贴。

🧰标注面板：朗读 / 复制 / 粘贴

是什么标注面板每条标注附带三个操作：🔊 朗读（TTS 读出原文与备注）、📋 复制（复制标注文本）、📥 粘贴（把标注文本插入当前光标处）。面板标题栏有醒目的「✕ 关闭」按钮。
怎么用菜单栏「🖍️ 标注」打开面板 → 每条右侧点击对应按钮；朗读引擎在「设置 → 朗读 TTS」中配置。
路径菜单栏「标注」→ 面板内 🔊 / 📋 / 📥 按钮

🔊朗读（TTS）

是什么文字转语音朗读。系统内置引擎免配置、离线可用（桌面与安卓均支持）；也可切换 OpenAI 兼容接口（/audio/speech），自定义接口地址、Key、模型与音色。
怎么用「设置 → 朗读 TTS」选择引擎、填好配置、点「🔊 试听」验证；朗读入口在标注面板每条的 🔊 按钮。单次朗读最长 3000 字。
路径菜单栏「设置」→ 朗读 TTS

✏️划线 / 高亮 / 备注

是什么给选中文字添加高亮、下划线或备注；备注在悬停标注文字时显示。
怎么用在编辑器中选中文字 → 右键 →「标注」，选择颜色 / 下划线 / 写备注。标注随编辑自动位移，并按文件路径持久化。
路径选中文字右键 → 标注

🎨高亮颜色选择

是什么内置 5 色高亮色板：黄、绿、蓝、粉、橙。
怎么用在标注右键菜单中点击对应色块即可给选中文字上色。
路径选中文字右键 → 标注 → 色板

📋标注导航面板

是什么列出当前文件的所有划线 / 高亮 / 备注，点击条目跳转到对应位置。
怎么用点击菜单「标注」（按钮高亮）打开导航面板，从列表中快速定位；读书、审稿、Code Review 都适用。
路径菜单栏「标注」

08 🎬 宏

把一串编辑动作录下来，一键重放，重复操作省事。

⏺️录制宏

是什么录制输入文本与按键动作；录制时按钮变为「停止录制 ●N」并实时显示动作数。
怎么用Ctrl+Shift+R 开始 / 停止录制，或点击菜单「录制宏」。
路径菜单栏「录制宏」　快捷键Ctrl+Shift+R

▶️回放宏

是什么按顺序重放已录制的动作；尚未录制时按钮不可用。
怎么用Ctrl+Shift+P 回放，或点击菜单「回放宏」。
路径菜单栏「回放宏」　快捷键Ctrl+Shift+P

💾宏管理：保存 / 回放 / 重命名 / 删除

是什么把当前录制的动作保存为「命名宏」，永久保留（存于本机），可随时按名称回放，也可重命名或删除。
怎么用先「录制宏」并停止录制 → 点菜单「宏管理」→ 在顶部输入名字并保存。之后在列表点宏名（▶）即可从当前光标处回放。
路径菜单栏「宏管理」

📦宏的导入 / 导出

是什么所有命名宏可一键导出为一个 JSON 文件备份，或从 JSON 文件导入，方便跨设备迁移与分享。

# NotePP v0.11.2 发布说明

发布日期：2026-11-18

## 新功能：Markdown 渲染三件套

预览、对比预览、导出 HTML、打印 PDF 四个出口同步生效：

### 1. 数学公式（KaTeX）
- 行内公式 `$E=mc^2$`、块级公式 `$$\int_0^1 x^2 dx$$` 全部渲染为数学排版
- 同步渲染，公式即写即显；代码块 / 行内代码里的 `$`（如金额 `$5`）不会误判为公式

### 2. Mermaid 图表
- ` ```mermaid ` 代码块自动绘制为流程图 / 时序图 / 甘特图等
- 图表语法有误时保留源码展示，不中断预览

### 3. 代码块语法高亮（highlight.js）
- 按语言染色（js/ts/python/rust/go/java/sql/css/html 等常见语言）
- 未指定语言时自动检测

### 导出说明
- 应用内预览 / 对比预览 / 打印：完全离线可用（依赖已内置）
- 导出的 HTML 文件：公式样式与 mermaid 脚本引用 jsdelivr CDN，打开时需联网（公式本体已内联，联网只为加载样式/脚本）

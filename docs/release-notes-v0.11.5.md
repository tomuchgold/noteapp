# NotePP v0.11.5

## 改进：当前行/段落高亮辨识度

**定义说明**
- 当前行：光标所在的单独一行
- 当前段落：从光标行向上/向下扩展到空行为止的连续非空行块

**改动**
- 默认高亮从「主题面板底色」（与背景同族、不明显）改为**主题强调色淡染**，与背景拉开层次
- 行最左侧新增**强调色竖条**（VS Code 风格），一眼锁定光标位置
- 与标注区分：标注作用于选中的文字色块（黄/绿/蓝/粉/橙固定五色），当前行高亮作用于整行底色+左竖条，形态与色彩体系都不同
- 仍可在 设置 → 高亮颜色 完全自定义；「跟随主题」恢复默认淡染

## 测试
颜色/竖条 9 项 + 全量回归 87 项通过。

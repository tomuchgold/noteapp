# NotePP v0.11.3

## 修复

- **保存后继续编辑被误判丢失（重要）**：保存成功后磁盘基线未刷新，下一次变更监听节拍会把「自己的保存」误判为「文件被外部程序修改」，弹出「重新加载（放弃我的修改）」后继续编辑的内容被回退——表现为「保存提示成功，再打开还是没改」。已修复：保存后立即刷新基线；监听检测到改动时先比对内容，内容相同不再提示；弹窗按钮改为「保留我的版本」为主按钮防误点。附 9 项端到端回归（含真·外部修改检测反向验证）。
- 修复右键标注选区丢失（v0.9 起右键菜单打开时选区被 CodeMirror 吞掉，标注实际未写入——于 v0.11.0 已修，本版补充测试覆盖）。

## 新增

- **光标行高亮颜色可自定义**：设置新增「高亮颜色」色板，光标所在行/段落背景色可任意设定，不再受主题默认配色不明显的影响；支持「跟随主题」一键恢复，切换主题后自定义色保留。
- **Markdown 渲染三件套**（预览 / 对比预览 / 导出 HTML / 打印四处同步生效）：
  - KaTeX 数学公式：行内 `$E=mc^2$`、块级 `$$...$$`
  - Mermaid 图表：` ```mermaid ` 流程图/时序图等直接画图
  - 代码块语法高亮：基于 highlight.js，自动识别语言

## 测试

全量 112 项通过：纯逻辑 21 + 保存安全 9 + 颜色设置 8 + UI 功能 24 + 回归 50（v0.10 / v0.9）。

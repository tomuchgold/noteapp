# NotePP v0.11.6

## 新增 / 改进

- **「我的网站」入口**：菜单栏新增按钮（最右侧），点击调用系统浏览器打开 `https://notepp.ambook.vip`。
  > 注意：官网目前尚未实际部署上线（域名仍指向旧页面），需按 `site/DEPLOY.md` 将 `/workspace/site/` 上传后此入口才能看到正确内容。
- **查找范围「所有标签」**：查找窗口新增第三个页签，可一次搜索所有已打开标签的内容，按文件分组显示命中行；点击结果直接切换到对应标签并跳转该行。未保存标签也可搜索。
- **查找窗口改为可拖动浮窗**：不再是底部固定条；按住标题栏（⠿ 手柄）可任意拖动，位置自动记住；可与编辑区同时显示，不挡下方内容。
- **底部「搜索结果面板」保持原样**（你要求不变）：行号+命中行内容+高亮+点击跳行。
- 修复：焦点不在查找框时按 Esc 关不掉浮窗的问题（全局 Esc 均可关闭）。

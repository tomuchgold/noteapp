# NotePP v0.11.0 发布说明

发布日期：2026-11-18

## 新功能

### 1. 搜索结果面板（Notepad++ 风格）⭐
查找栏新增「结果面板」按钮：在编辑器下方弹出独立面板，按行列出全部命中——
- 每条显示 **行号 + 命中行完整内容**，命中词黄色高亮
- **单击任意一行直接跳到该处**，当前命中所在行在面板中加亮标记
- 与逐个跳转（Enter / ↑↓）互补：先总览再定点

### 2. 分屏对照
菜单栏「分屏」按钮：左右两个编辑器同屏显示两个文件，各自独立编辑、语法高亮独立生效。
右侧顶部下拉可切换分屏文件，× 关闭分屏。（手机端自动隐藏）

### 3. 标注导航面板
菜单栏「标注」按钮：当前文件全部划线/高亮/备注按位置排序列出，
显示标注摘录与备注，**点击跳转到标注位置**，× 删除单条。标注多了再也不怕找不到。

### 4. 打印 / 导出 PDF
菜单栏「打印」按钮或 **Ctrl+P**：按当前缩放字号生成带样式文档（Markdown 走渲染、纯文本走等宽排版），
调起系统打印对话框——打印机里选「另存为 PDF」即得 PDF。v0.9 的缩放至此真正闭环：放大 → 打印 → 大字 PDF。

### 5. 外部文件变更监听
每 3 秒 + 窗口聚焦时检查已打开文件的修改时间/大小：
- 文件被外部程序修改且**无未保存编辑** → 静默重载最新内容
- 有未保存编辑 → 弹窗让你选「重新加载」或「保留我的版本」，杜绝覆盖他人改动

### 6. 安卓体验细化
- **双指捏合调整字号**（对应桌面 Ctrl+滚轮），步进 5%
- 软键盘弹出自适应（`interactive-widget=resizes-content` + 可视区滚动补偿），输入框不再被遮挡

### Bug 修复
- **右键标注失效**：右键的 mousedown 会把 CodeMirror 选区 collapse 到点击处，导致「高亮/划线/标注信息」实际写入失败。现在右键前缓存选区，标注恢复正常（v0.9 引入的回归，v0.11 修复）

## 安装
- Windows：`NotePP_0.11.0_x64-setup.exe` / `.msi`
- macOS（Apple Silicon）：`NotePP_0.11.0_aarch64.dmg`
- Linux：`.deb` / `.rpm` / `.AppImage`
- Android：`NotePP_0.11.0_universal.apk`（自签名，安装时允许「未知来源」）

> 桌面包与 APK 均未做代码签名，首次运行可能遇到 SmartScreen / Gatekeeper 提示，选择「仍要运行」即可。

# NotePP v0.11.1 发布说明

发布日期：2026-11-18

## 新功能：对比视图支持 Markdown 预览

「对比」功能升级为双模式（对比窗口右上角切换）：

- **逐行对比**（原有，已增强）：逐行差异 + 改动行高亮，现在两侧按文件类型做**语法着色**（Markdown/代码/JSON 等），定位改动更直观
- **渲染预览**（新增）：左右两栏并排显示 Markdown **渲染后的排版效果**（标题/加粗/列表/表格/代码块），目视对照两版文档的最终呈现；非 Markdown 文件在预览模式下按原文显示

典型用法：改完一版文档想看看「改前 vs 改后」的排版差异——逐行对比看改了什么，渲染预览看效果差别。
